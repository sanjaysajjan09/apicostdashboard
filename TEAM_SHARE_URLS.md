# 🚀 Shareable Application URLs for Your Team

## Quick Access

### Method 1: Launch Application (Recommended)
1. Go to: **https://coder.prod.joveo.com/**
2. Open your workspace
3. Click **"Launch Application"** button
4. Select **"Next.js App"** from the list

This will automatically open the dashboard in a new tab.

---

### Method 2: Direct URLs

**Main Dashboard (Combined View)**:
```
https://<workspace-name>--3000.coder.prod.joveo.com/techopsdashboard
```

**Individual Dashboards**:
- Publisher API Cost Analysis: `https://<workspace-name>--3000.coder.prod.joveo.com/publisher-cost-analysis`
- Indeed Last Successful Stats Fetch: `https://<workspace-name>--3000.coder.prod.joveo.com/last-stats-sync-status`

**API Endpoints**:
- Health Check: `https://<workspace-name>--5001.coder.prod.joveo.com/health`
- Snowflake Health: `https://<workspace-name>--5001.coder.prod.joveo.com/health/snowflake`

> **Note**: Replace `<workspace-name>` with your actual Coder workspace name

---

## How to Find Your Workspace Name

1. Check your Coder dashboard URL
2. Look at the workspace name in the URL path
3. Or check: `hostname` command output (workspace name is usually part of it)
